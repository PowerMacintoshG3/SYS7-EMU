### Mac OS 7 Macintosh Quadra 800 Emulator Launcher

A one-click, standalone desktop launcher wrapper designed to boot a legacy Macintosh Quadra 800 layout directly into System 7.5.5 using the power of the QEMU emulation engine. 

### Key Features

* **One-Click Deployment:** Skips complicated terminal configuration parameters and launches your desktop environment instantly.
* **Architecture Support:** Built natively as a Universal Binary matching both Apple Silicon and Intel Mac systems.
* **Smart Setup Assistant:** Includes an integrated installation helper to set up your backend compiler environments seamlessly.

### Quick Start & Installation

1. Download the latest compiled release or disk installer file.
2. Launch the app installer to trigger the background setup assistant.
3. Select your deployment configuration preference: 

  * **Silent Background (Hidden):** Pulls down and builds all compiler assets silently without interrupting your desktop workspace.
  * **Visible Terminal (Watch Process):** Opens a console environment allowing you to track the exact build progress live.
4. Once components are configured, click the primary launch button to load your system canvas.


### Technical Specifications

* **Emulated Hardware Target:** Macintosh Quadra 800 Profile
* **Operating System Environment:** System 7.5.5
* **Core Emulation Framework:** qemu-system-m68k
* **Minimum Host Target Requirements:** macOS 14 or later (Sonoma, Sequoia, Tahoe, Golden Gate)
